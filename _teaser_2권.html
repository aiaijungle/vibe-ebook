핵심 공식
CIF — 이 공식 하나로 다 된다

AI에게 "좋은 웹사이트 만들어줘"라고 하면 쓰레기가 나온다. 이건 AI 탓이 아니다. 지시가 멍청한 거다. AI는 지시 품질에 비례해서 결과를 뱉는다. 나는 이걸 반복하다가 공식을 만들었다. CIF다.

C (Context) — 지금 상황이 뭐야?
"나는 호텔 예약 앱을 만들고 있어. Python이야. 파일은 payment.py."

I (Intent) — 뭘 하고 싶어?
"카카오톡으로 예약 확인 메시지를 자동으로 보내고 싶어."

F (Format) — 결과물은 어떤 형태?
"send_kakao() 함수 하나만 만들어줘. 다른 코드는 건드리지 마."

이 세 줄이면 AI가 정확히 뭘 해야 하는지 안다. 헤매지 않는다. 되묻지 않는다. 바로 뽑아낸다. CIF는 편리함을 위한 공식이 아니라 시간을 지키기 위한 공식이다.

4장 실습 미리보기
10분 만에 수집봇 실제 구동 — 코드 0줄로 시작

코드를 한 줄도 안 쓴다. Claude한테 말로 시키면 끝이다. 4장에서 실제로 하는 과정이다.

STEP 1 — Claude에게 말로 시킨다
"파이썬으로 네이버 뉴스에서 '바이브코딩' 키워드 기사 제목 10개를
수집해서 news.txt 파일에 저장하는 봇 만들어줘."
STEP 2 — Claude가 코드를 통째로 뽑아준다
# Claude가 만들어준 코드 — 복붙만 하면 된다
import requests
from bs4 import BeautifulSoup

url = "https://search.naver.com/search.naver?query=바이브코딩&where=news"
soup = BeautifulSoup(requests.get(url).text, 'html.parser')
titles = [a.text for a in soup.select('.news_tit')[:10]]
open('news.txt','w').write('\n'.join(titles))
STEP 3 — 실행 결과 (약 4초)
✅ news.txt 생성 완료 · 기사 제목 10개 수집
→ 에러 나면? Claude에 붙여넣기 → 수정본 즉시 받기

4장에서 이 봇을 슬랙 알림 → 엑셀 저장 → 매일 자동 실행까지 확장한다. 모두 Claude에게 말로 시킨다. 직접 코드 한 줄도 안 쓴다.
