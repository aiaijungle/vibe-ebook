목적: 저자의 실제 경험은 남기고, 수익 약속·근거 없는 수치·"사람은 아무것도 안 해도 된다"류 문장만 걷어낸다.
기준: API 키 보호·덮어쓰기 금지 같은 **안전 규칙의 '절대'·'무조건'은 유지**했다. 저자 본인 사례(96시간, 봇 9개 등)는 유지했다. 환불·가격 문구는 운영 결정이라 바꾸지 않았다.

- "인간의 눈으로는 절대 찾을 수 없습니다" → 눈으로 찾기는 어렵습니다

## 3권 《AI 에이전트 바이블》 (`agent-bible.html`)

- "과장이 아닙니다. 숫자로 증명하죠." → "숫자로 보겠습니다."
- "1.7억 원 절감 — 이론이 아닌 실제 운영 수치" → 저자 회사 업무 구성에서 계산한 수치이며 크게 달라질 수 있음
- "경쟁사는 AI로 4배 효율, 당신은 아직 손으로" → 반복 업무가 많은 조직일수록 차이가 빨리 벌어지니 내 업무부터 확인
- "실제 사례: 숫자가 증명하는 것" → "사례로 보는 변화 — 수치는 각 회사·환경에 한정"

- **임금 격차 단락:** 보고서 연도(2024 → 2023)와 23%의 의미(AI 협업 → 일자리 생성·소멸 구조 변화)를 바로잡음. 출처를 확인할 수 없는 "2027년 예측 연봉(Glassdoor + LinkedIn 종합)" 표와 "연봉 2~3배" 단정을 삭제하고, 일의 범위 차이가 보상 차이로 이어진다는 설명으로 대체
