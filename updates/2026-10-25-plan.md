# AI 바이블 전권 실전 보강 — 2026-10-25

## 목적

각 권을 읽은 뒤 독자가 자기 업무에 쓸 수 있는 문서나 검증 결과를 하나씩 남기게 한다. 5권은 에이전트의 공통 언어와 지도라는 비유로 온톨로지를 설명한다.

## 권별 구성

| 권 | 추가 내용 | 독자 산출물 |
|---|---|---|
| 1 | AI에게 처음 맡길 업무 하나 | 완료 기준이 있는 업무지시서 1장, 사실 확인표, 7일 실행 기록을 만듭니다. |
| 2 | 말로 만든 도구를 고객이 쓸 수 있게 | 가상 예약 스튜디오의 요구사항 1장과 출시 전 확인할 실패 사례 8개를 만듭니다. |
| 3 | 에이전트 한 명에서, 이어지는 업무로 | 업무 인수인계 양식, 승인 대기 상태, 실패 복구 기준을 설계합니다. |
| 4 | AI가 고친 코드를 믿기 전에 | 실행 가능한 읽기 전용 예제로 0회와 정보 누락, 중복 예약을 구분하고 검사합니다. |
| 5 | AI 에이전트가 노는 세상, 온톨로지로 쉽게 시작하기 | TBox·ABox를 구분하고, 업무 질문을 데이터·규칙·행동으로 연결한 작은 지도를 완성합니다. |

## 유지하는 원칙

- 기존 원본의 독자 흐름, 결제 링크, 잠금 해제, 공유, 읽기 기록을 보존한다.
- 지침과 실행 권한을 구분한다. 에이전트는 서비스 권한을 우회하지 않는다.
- 반복 절차와 판단을 구분하고, 필요한 실행은 승인·실행·검증을 나눈다.
- 근거·출처·확인 시각을 표시하고, 정보 누락을 사실로 채우지 않는다.
- 실제 고객·협력사·프로젝트·계정·연락처·인증정보를 새 콘텐츠에 사용하지 않는다.
- 모든 예제는 독립적으로 만든 가상 스튜디오·공방·쇼핑몰·작업장 사례다.
- 모델명·요금·제품별 출시 일정 나열보다 오래 쓸 수 있는 실행 원칙을 다룬다.

## UI/UX

각 장은 쉬운 설명 → 예시 → 복사 가능한 템플릿 → 확인표 순서다. 새 고정 버튼은 추가하지 않는다. 상단 안내·기존 업데이트 팝업·목차에서 추가 장으로 이동한다. 템플릿 복사와 텍스트 저장은 명시적으로 누를 때만 동작한다. 실습 버튼은 네트워크 요청이나 실제 쓰기를 하지 않는다. 체크 기록은 해당 브라우저의 해당 책에만 저장한다.

기존 업데이트 대화상자에는 접근성 이름, Escape 닫기, 키보드 초점 순환과 닫은 후 초점 복귀를 보강한다. 좁은 화면의 표는 영역 안에서 넘겨 읽고 본문에는 한 열을 사용한다.

## 범위

국문 1~5권 HTML 본문, 판매페이지의 실습 안내, 검색용 요약, 공통 실습 예제를 보강한다. 영문·일문 번역 및 배포된 PDF의 재생성은 이번 범위에 포함하지 않는다. 기존 가격·상품·결제 설정은 변경하지 않는다. 이전 기술 동향 노트의 제품별 주장은 이번 보강의 검증 범위가 아니다.
