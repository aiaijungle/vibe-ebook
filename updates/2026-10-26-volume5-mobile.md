- 요청: 업로드한 휴대폰 화면에서 확인된 5권 UI 문제 점검 및 보완

## 검증 범위

- 클라우드 Chrome에서 폭 320, 360, 390, 412, 600, 768, 1024px인 iframe으로 반응형 화면을 검사했다. iframe의 기본 스크롤바 때문에 실제 콘텐츠 폭은 설정한 폭보다 15px 좁았다.
- 각 크기에서 문서 전체의 가로 넘침 없음, 상단 제목 높이와 구매 버튼 위치, 업데이트 본문의 비구매자 숨김을 확인했다.
- 목차 아이콘 클릭 → 장 이동 → 목차 닫힘, 고정 헤더 아래 장 제목 위치, 업데이트 대화상자 열기/닫기, 선물 창, 다크 모드, 하단 배너 닫기를 실제 UI로 점검했다.
- 검토용 페이지는 기존 `author=1` 옵션으로 iframe 크기를 개발자 도구로 오인하는 검토 방해만 피했다. 잠금 해제는 수행하지 않았다.
- 새 JavaScript 구문 검사 및 `git diff --check` 통과.
- 실제 스마트폰 브라우저와 가상 키보드, 정상 구매 비밀번호를 이용한 해제, 실제 결제·SNS 발송은 이번 UI 검사에 포함하지 않았다.

## 변경 경계

5권 전용 스타일·스크립트 및 기존 공통 스크립트의 5권 한정 로더를 변경한다. HTML 원본은 수정하거나 재업로드하지 않고, 화면에 이미 표시된 메뉴·가격 안내의 배치만 DOM으로 정리한다. 가격·결제 목적지·구매자 비밀번호 검증·본문 잠금·영문·다른 권의 동작은 유지한다. 본문의 사실 주장이나 통계 수치의 검증은 이 UI 수정에 포함하지 않는다.

## 공개 반영 승인

2026-10-26 사용자가 수정안의 공개 반영을 승인했다. 기존 HTML 전체 업로드는 자동 검토에서 차단되어, 결제·잠금 정보가 없는 화면용 파일만 반영하는 방식으로 전환했다. 검토용 HTML 패치는 적용하지 않는다. 공통 파일의 로더는 정확히 practical-bible.html에서만 실행한다.
