## 바이브 코딩 전체 흐름 (책의 지도)

```
📦 SETUP  베이스캠프 구축
   [1] 폴더 고립화 (프로젝트별 분리)        ← 2장
   [2] VS Code 설치 → Python 설치 → Claude Code 연결      ← 2장
   [3] MASTER.env에 API 키 입력 (.gitignore 설정 필수)     ← 9장

⚡ ENGINE  AI 명령 시스템
   [4] 감정 프롬프팅 (비즈니스 목적 → AI 주입) ← 8장
   [5] 에러 멱살잡기 (에러 로그 그대로 AI에 던지기) ← 5장

🤖 PRODUCTION  자동화 시스템
   [6] 봇 공장 가동 (반복 작업 → 봇)       ← 6장·11장
   [7] 에이전트 (판단 자동화)                ← 7장
   [8] 오케스트레이터 (팀 조율)              ← 11장

💰 MONETIZATION  수익화
   [9] 랜딩페이지 → 0원 외주              ← 12장
   [B] 클라이언트 영입 → B2B 세일즈 파이프라인   ← 12장
```
