Where should I start?

For a gradual learning path, read 1 → 2 → 4 → 3 → 5: draft, build, verify, coordinate, operate. If you manage a team, start with the operating decisions in Volume 5 and use the other books when you need implementation detail.

Is the English edition available?

Yes: all five volumes have English web readers and English practice companions. Original cases are drawn from Korean business operations. Some code strings, screenshots, videos and linked sources retain Korean. Inspect your intended reader before buying; contact support if you need a fully localized workshop or specific download format.

How does reader access work?

Readers use the existing purchase and unlock flow. Check the checkout page for current terms. For purchase or access help, contact housepeoplekorea@gmail.com.

Can my team use this in a workshop?

Send the audience, team size, task you want to improve, preferred language and intended use. Book access, group licensing, workshop delivery and implementation are separate questions; agree the scope before organizing a team session.
