1. Claude 5 세대 요금이 크게 내려갔습니다

Anthropic 공식 1st-party API 기준(1M 토큰당 입력/출력): Claude Opus 5.5 $4 / $20, Sonnet 5.5 $2 / $10, Haiku 5.5 $0.10 / $0.50, Fable 5.1 $10 / $50. 특히 Haiku 5.5는 이전 Haiku 4.5($1 / $5)의 10분의 1입니다.

독자가 할 일
  • 분류·요약처럼 양이 많은 작업의 월 비용을 다시 계산해 보세요. 비싼 모델을 쓰던 작업 일부는 작은 모델로 같은 품질이 나오는지 같은 과제로 비교합니다.

영향받는 곳: 3권 STEP 7 가격표, 4권 "모델 선택" 표 — 이번 개정에서 갱신 완료

2. API 버전 2026-10-21부터 temperature·top_p·top_k를 보내면 오류

이 버전의 API를 쓰는 요청은 모델과 관계없이 temperature, top_p, top_k 파라미터를 보내면 400 오류를 받습니다. 최신 SDK로 올리면 이 버전이 적용될 수 있습니다.

독자가 할 일
  • 예전 블로그·강의에서 복사한 코드에 temperature=0.7 같은 줄이 있다면 지우세요. AI 바이블 본문 예제에는 해당 파라미터가 없습니다.

영향받는 곳: 2·3·4권의 API 예제를 직접 고쳐 쓰는 독자

3. 예제 코드의 모델 ID는 새 이름으로

3·4권 예제 일부는 claude-sonnet-4-6, claude-opus-4-7 같은 이전 세대 ID를 씁니다. 지금도 쓸 수 있는 모델이 있지만, 새로 만드는 코드는 claude-opus-5-5, claude-sonnet-5-5, claude-haiku-5-5를 기준으로 하세요. 5세대에서는 고정 사고 예산(budget_tokens)과 강제 도구 호출(tool_choice any/tool)이 거부됩니다.

독자가 할 일
  • 모델 ID를 바꾼 뒤 같은 입력으로 한 번 실행해 오류가 없는지 확인합니다. 바뀐 점 3가지는 각 권의 "2026.10 업데이트 노트"에 정리돼 있습니다.

영향받는 곳: 3권 STEP 3·4·6, 4권 API 연동 장
